Price Selector Picker Tool

The Selector Picker helps you find the CSS selector for any price element on a product page. This is useful when auto-detection doesn't find the price.

Step 1 — Install

Drag this button to your bookmarks bar:

🎯 Pick Selector

Can't drag? Right-click the button → Bookmark This Link (Firefox) or copy the link address and create a bookmark manually.

Step 2 — Use

  1. Navigate to the product page you want to monitor
  2. Click Pick Selector in your bookmarks bar
  3. Hover over the page — elements highlight in green as you move
  4. Click the price element — the CSS selector is copied to your clipboard
  5. Return here and paste it into the CSS Selector field when adding or editing a product

Step 3 — Test It

Try the picker right here to make sure it works in your browser:

Click any element on this page after activating

Tips

  • Click the actual price number, not a surrounding container
  • If auto-detection works for your site, you don't need a manual selector at all
  • Some sites block bookmarklets via Content Security Policy — use the browser console fallback if needed
Browser-specific notes

Chrome/Edge: Show the bookmarks bar with Ctrl+Shift+B (Cmd+Shift+B on Mac). Drag the green button directly onto it.

Firefox: If dragging doesn't work, right-click the green button and choose "Bookmark Link".

Safari: Enable "Show Develop menu" in Preferences → Advanced, then drag the button to your Favorites bar.
