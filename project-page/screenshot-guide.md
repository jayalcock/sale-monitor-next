# Screenshot Guide

Recommended screenshots to capture for the project page. Take these from your
live instance at the deployed dashboard.

## Required (include in post)

1. **Dashboard - Table View**
   Show the main dashboard with several products, price columns, status indicators,
   and the trends chart at the top. This is the hero image.

2. **Product Detail Page**
   Pick a product with good price history (ideally showing a visible drop).
   Show the chart and statistics panel.

3. **Dashboard - Card View**
   Switch to card view showing the grid layout with product images and grouped
   product cards collapsed.

## Nice to Have

4. **Alerts Page**
   Capture with a few active alerts showing different badge types (target met,
   discount, failing extraction).

5. **Grouped Product Comparison**
   Show a product group detail page with multiple retailers and the combined
   price chart.

6. **Manage Page**
   Show the add/edit product modal with alert rule checkboxes and notification
   channel options visible.

7. **Mobile View**
   Browser dev tools or phone screenshot of the dashboard in card view at a
   narrow viewport. Shows responsive layout.

8. **Notification Example**
   Screenshot of a Discord or email notification showing a price drop alert.

## Tips

- Use the live instance with real product data for authentic screenshots
- Crop browser chrome if it adds clutter, but leave the URL bar if you want
  to show it's self-hosted
- Dark theme is the default -- keep it for consistency
